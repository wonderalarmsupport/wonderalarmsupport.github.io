隐私政策

本隐私政策适用于移动设备应用程序 Wonder Alarm，以及由 AlphaMu Studios（以下统称"本应用"）运营的任何相关服务。AlphaMu Studios 在本政策中称为"个人信息处理者"或"我们"。

本政策依据《中华人民共和国个人信息保护法》（以下简称"个人信息保护法"或"PIPL"）及相关法律法规制定，适用于中国大陆地区的用户。

我们收集的个人信息

本应用本身不会直接收集您的个人信息。但是，当您下载和使用本应用时，第三方服务可能会自动收集相关信息。

您的闹钟设置、自定义标签、自定义铃声、睡眠记录、睡眠评分，以及饮水和拉伸打卡数据，仅保存在您的设备本地，我们的服务器不会收集或存储这些数据，也不会由我们传输给任何第三方。

可能通过第三方服务自动收集的信息包括：

  • 设备的互联网协议（IP）地址
  • 设备标识符（如广告标识符，以及在适用设备和服务中使用的其他设备标识符，例如 GAID 或 OAID）
  • 您访问的应用页面、访问时间和日期、在相关页面停留的时长
  • 使用本应用的总时长
  • 应用崩溃日志、非致命错误信息及性能分析数据
  • 您使用的移动操作系统版本

本应用不会直接收集您的姓名、电子邮箱地址或电话号码等身份识别信息。但第三方服务可能出于分析、广告和崩溃报告的目的，处理与设备相关的标识符和使用数据。

本应用还允许您选择城市、基准货币以及应用内显示语言。为提供天气、汇率和新闻内容，您选择的城市名称、货币代码以及应用语言会被发送至我们自己的后端服务。对于新闻功能，系统会读取设备系统设置中的地区和语言信息（并非在应用内单独选择，也不涉及 GPS 或其他精确地理位置信息），以便获取与该地区相关的新闻标题。在任何情况下，仅上述必要信息会被转发至第三方天气、货币和新闻数据提供方，用于获取并展示相关内容，不会转发您的姓名、电子邮箱地址等身份识别信息。

新闻缩略图（如有）直接从原始发布者自己的服务器加载，这是新闻和 RSS 阅读应用的标准做法。这意味着当此类图片加载时，您的设备会直接连接该发布者的服务器，该发布者因此可能会看到您设备的 IP 地址及标准网络请求信息（与您浏览任何普通网页时的情形相同）。

我们自己的后端服务在每次请求时都会获取您设备的 IP 地址，用于限流及防止服务被滥用——该 IP 地址会经过哈希处理后使用，相关记录在数分钟内自动删除。您输入的城市名称也会经过哈希处理后作为缓存键使用，仅用于避免对第三方天气服务提供方重复发起相同请求。


敏感个人信息

我们的服务器不会收集或存储您的睡眠记录、睡眠评分、饮水记录或拉伸记录；这些数据仅保存在您的设备本地，因此也不会由我们向第三方传输或用于服务器端处理。

本应用请求您输入的城市名称仅用于获取天气信息，不涉及对您的精确地理位置或行踪轨迹的持续追踪。本应用不会主动请求或处理生物识别信息、宗教信仰、特定身份、金融账户等《个人信息保护法》所界定的敏感个人信息。


处理目的、方式和法律基础

我们处理个人信息的目的仅限于：提供闹钟及提醒服务、展示天气/空气质量/汇率/新闻简报、提供健康提醒功能、进行必要的崩溃分析与服务改进，以及展示广告（如适用）。

对于不同的处理活动，我们依据《个人信息保护法》第十三条所规定的相应合法性基础进行处理，包括在适用情况下基于您的同意（例如通过同意管理机制做出的广告及分析相关选择），以及为提供您主动请求的服务（如天气、汇率、新闻查询）所必需的处理。

保存期限见下文"数据保留政策"部分。


应用所需的设备权限

为了作为一款可靠的闹钟应用正常运行，本应用需要以下系统权限。我们仅使用这些权限来实现应用的核心功能，不会因此收集、存储或传输任何个人数据：

  • 精确闹钟权限（SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM）：用于确保闹钟在您设定的确切时间响起。
  • 通知权限：用于在状态栏显示闹钟的活动状态并触发提醒。
  • 电池优化设置：本应用会打开系统的电池优化列表，供您手动将本应用排除在外，防止 Android 系统使应用休眠，从而确保闹钟在设备深度休眠状态下仍能可靠响起。
  • 系统悬浮窗/显示在其他应用上层：用于在闹钟响起时，在锁屏或其他正在运行的应用上方显示全屏闹钟停止界面，以及在您设置的就寝时间显示就寝提醒弹窗。
  • 全屏意图权限（USE_FULL_SCREEN_INTENT）：用于在闹钟触发时，直接在锁屏上方启动闹钟响铃界面，使您能够立即看到，而不仅是收到一条通知。
  • 前台服务权限（FOREGROUND_SERVICE、FOREGROUND_SERVICE_MEDIA_PLAYBACK）：用于确保闹钟响起期间铃声能够在后台持续可靠播放。
  • 接收设备启动完成权限（RECEIVE_BOOT_COMPLETED）：用于在设备重启后自动重新设置您的闹钟，无需您重新打开应用。

Cookie 和追踪技术

本应用或其第三方 SDK 可能使用 Cookie、SDK、像素标签、设备标识符及类似技术，以支持功能实现、数据分析、服务提供和广告投放。在适用法律要求的情况下，我们会在使用非必要的追踪技术前获取您的同意。


您依据《个人信息保护法》享有的权利

根据《个人信息保护法》第四章的规定，您享有以下权利：

  • 知情权和决定权：了解并决定您的个人信息的处理情况
  • 查阅权和复制权：查阅、复制您的个人信息
  • 可携带权：在符合国家规定条件时，请求将您的个人信息转移至您指定的其他个人信息处理者
  • 更正、补充权：对不准确或不完整的个人信息进行更正或补充
  • 删除权：在法定情形下请求删除您的个人信息
  • 解释说明权：要求我们对个人信息处理规则进行解释说明
  • 撤回同意权：随时撤回您此前给予的同意，撤回不影响撤回前基于同意已进行的处理行为的效力
  • 限制处理权：在法律规定的情形下，请求限制对您个人信息的处理
  • 拒绝权：拒绝他人仅通过自动化决策方式作出对您权益有重大影响的决定（本应用不涉及此类自动化决策）

如需行使上述权利，请通过以下邮箱联系我们：wonderalarm.support@gmail.com。我们将在适用法律规定的期限内处理您的请求，并在必要时向您说明处理结果或无法满足请求的理由。


第三方 SDK 与信息共享（SDK 目录）

为保障应用的核心功能稳定运行、进行必要的分析与故障诊断、以及实现广告等商业化功能，我们接入了以下第三方服务/SDK。它们可能根据各自适用的隐私政策、服务条款以及与我们的服务安排，作为独立个人信息处理者、受托处理方或服务提供商处理相关信息：

（一）接收设备/使用数据的服务商：

  • Google Play Services / Firebase Analytics / Firebase Crashlytics / Firebase Remote Config / Firebase Installations — 运营方：Google LLC；收集数据：设备标识符、应用崩溃日志、性能诊断数据、使用统计、安装标识符；目的：崩溃分析、性能优化、远程配置、使用统计；隐私政策：https://policies.google.com/privacy
  • AdMob / Google 用户消息平台（UMP） — 运营方：Google LLC 及合作广告主；收集数据：设备标识符（如广告标识符，以及在适用设备和服务中使用的其他标识符）、广告互动数据；目的：广告展示及用户隐私同意管理；隐私政策：https://policies.google.com/privacy
  • Google Play 应用内评价 — 运营方：Google LLC；目的：应用内评分与评价功能；隐私政策：https://policies.google.com/privacy
  • Google Cloud Platform（我们自己的后端基础设施，包括 Firestore 和 Cloud Functions） — 运营方：Google LLC；收集数据：请求所需的城市名称、货币代码、语言选择，以及经哈希处理的 IP 地址；目的：提供天气、空气质量、汇率、新闻简报功能；隐私政策：https://cloud.google.com/terms/cloud-privacy-notice
  • OpenWeatherMap — 运营方：OpenWeather Ltd；收集数据：经由我们后端转发的城市名称（用于定位）及经纬度坐标；目的：提供天气与空气质量数据；隐私政策：https://openweathermap.org/privacy-policy
  • WeatherAPI.com — 运营方：WeatherAPI.com；收集数据：经由我们后端转发的城市名称；目的：当 OpenWeatherMap 暂时不可用时，作为天气数据的备用来源；隐私政策：https://www.weatherapi.com/privacy.aspx
  • NewsData.io — 运营方：NewsData.io；收集数据：地区代码、语言偏好；目的：获取新闻标题；隐私政策：https://newsdata.io/privacy-policy
  • Frankfurter API — 提供公开的汇率数据接口（基于欧洲央行参考数据）。Wonder Alarm 通过自身后端服务获取汇率数据，不向该服务传递终端用户的姓名、电子邮箱、电话号码、设备标识符或其他直接识别用户身份的信息。

（二）新闻内容来源（非直接接收您个人信息的处理者）：

The Conversation、Global Voices 等 RSS 新闻来源仅提供新闻内容本身；新闻缩略图由这些发布者自己的服务器直接提供给您的设备（见上文"新闻缩略图"相关说明）。这些内容提供方仅接收为获取相关内容所必需的请求参数，不会收到您的姓名、电子邮箱地址或其他直接身份识别信息。

我们不会出售您的个人信息。仅在以下目的范围内与上述第三方服务提供方共享必要信息：数据分析与使用统计、广告与商业化、崩溃报告与故障诊断、服务改进，以及根据您的设置提供天气、空气质量、汇率和新闻内容。


个人信息的跨境传输

由于本应用使用的部分第三方服务（如上文"第三方 SDK 与信息共享"所列）的服务器位于中国大陆以外地区，您的部分个人信息（主要为设备标识符、应用使用数据、崩溃诊断信息，以及您为获取天气、汇率、新闻内容而主动提供的城市名称、货币代码和语言选择，均不包含姓名、电子邮箱等直接身份识别信息）可能会被传输至中国大陆以外的国家或地区进行处理。

对于向中华人民共和国境外提供的个人信息，我们将在传输前依法向您告知境外接收方的名称、联系方式、处理目的、处理方式、个人信息类别以及您向境外接收方行使个人信息权利的方式和程序，并依法取得您的单独同意；法律、行政法规或者国家网信部门规定无需取得个人同意的情形除外。

如果根据适用的中国法律法规，相关个人信息出境不属于免予履行数据出境程序的情形，我们将在进行相关跨境传输前，依法履行适用的数据出境合规要求，包括根据适用情况开展个人信息保护影响评估，并通过个人信息保护认证、国家网信部门制定的标准合同，或其他适用的数据出境机制。

您有权就跨境传输向我们询问境外接收方的具体信息，并可通过本政策"联系我们"部分列明的方式行使您依据本政策享有的权利。


数据保留政策

我们按照实现处理目的所必需的最短时间保留个人信息：

  • 后端请求中经哈希处理的 IP 地址：数分钟内自动删除
  • 后端经哈希处理的城市名称缓存键：按缓存策略保留，仅用于减少重复的第三方请求
  • Firebase Analytics / Crashlytics / Remote Config / Installations 相关数据：按 Google/Firebase 各自产品的数据保留政策处理
  • 广告相关数据（AdMob）：按 Google 广告相关政策处理
  • 闹钟设置、自定义标签、自定义铃声、睡眠记录、睡眠评分、饮水与拉伸打卡数据：仅保存在您的设备本地，直至您手动删除、清除应用数据或卸载本应用

若收集到任何其他用户提供的数据，仅在实现其既定目的所必需的期限内保留，法律另有较长保留期限要求的除外。


未成年人个人信息保护

本应用不面向不满十四周岁的未成年人。我们不会在明知的情况下主动收集未成年人的个人信息，也不会向未成年人推广本应用。

本应用不会直接请求姓名、电子邮箱地址或电话号码等个人信息，但设备标识符和使用数据等信息可能会被第三方服务（如分析、广告和崩溃报告工具）自动收集。

如我们发现在未获得监护人同意的情况下收集了未成年人的个人信息，将立即删除相关信息。

如果您是监护人，并发现您的被监护人向我们提供了个人信息，请通过 wonderalarm.support@gmail.com 与我们联系，以便我们及时采取必要措施。
